Композиция

{% endcard_header %} {% card_body %}

Tabs → TabList → Tab + TabPanel. Каждый tab явно ссылается на panel через panel; автоматически созданных секций нет.

  • ARIA roles и связи рендерятся template tag.
  • Disabled tabs не участвуют в keyboard-навигации.
  • HTMX может заменить содержимое вкладки после явного refresh.
