Page

Корневой shell страницы: AppBar сверху, отдельная боковая навигация и рабочая область с независимой прокруткой.

{% endcard_header %} {% card_body %}

Page создаёт конечную область viewport и распределяет её между верхней панелью, sidebar и body. Он не навязывает содержимое и не добавляет скрытую разметку.

  • sidebar прокручивается отдельно от рабочей области;
  • body получает всё оставшееся пространство;
  • внутри можно использовать Layout, Panel и Card.
{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Как использовать

Разметка shell задаётся явно через page_sidebar и page_body.

{% endcard_header %} {% card_body %} 
{% verbatim %}{% page %}
  {% appbar %}
    ...
  {% endappbar %}

  {% page_sidebar %}
    {% panel width="full" height="full" %}
      Навигация
    {% endpanel %}
  {% endpage_sidebar %}

  {% page_body %}
    {% panel width="full" height="full" %}
      Рабочая область
    {% endpanel %}
  {% endpage_body %}
{% endpage %}{% endverbatim %}

Для частичных обновлений HTMX сохраняйте Page и заменяйте содержимое внутри page_body. Сам Page не имеет JavaScript API и не требует mount/unmount.
