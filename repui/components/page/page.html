Page

Page — корневая область интерфейса RepUI. Она связывает верхние области страницы и основное содержимое в один стабильный экранный shell.

{% endcard_header %} {% card_body %}

Статус | Stable

Использовать | Один раз для крупной страницы приложения, документации, административного интерфейса или рабочего экрана.

Не использовать | Для отдельных блоков внутри страницы. Для них предназначены Container, Grid, Stack, Panel и Card.

Page не показан внутри рабочей области: сам Workbench уже размещён внутри Page. Вложенная Page создала бы второй page-level shell и исказила бы проверку компонента.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Как устроена композиция

{% endcard_header %} {% card_body %}

Page задаёт внешний shell. Верхние элементы, например AppBar, размещаются непосредственно внутри Page, а основная рабочая область — внутри page_content. 

{% verbatim %}{% page %}
  {% appbar behavior="sticky" surface="glass" %}
    ...
  {% endappbar %}

  {% page_content %}
    ...
  {% endpage_content %}
{% endpage %}{% endverbatim %}

Внутри page_content можно использовать обычный Layout: Container, Grid и Stack.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Ответственность Page

{% endcard_header %} {% card_body %}
  • предоставляет корневую область страницы;
  • сохраняет стабильную вертикальную композицию shell;
  • отделяет верхние области от основного содержимого;
  • передаёт оставшееся пространство в page_content;
  • не управляет внутренней сеткой страницы;
  • не определяет оформление вложенных компонентов.
{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Page и Foundation

{% endcard_header %} {% card_body %}

Page опирается на Foundation, который обеспечивает первый стабильный кадр, базовую геометрию документа и page-level размеры.

Сам компонент не должен переопределять глобальные правила html, body, reset или собственный 100dvh вне общего Foundation-контракта.

Foundation отвечает за геометрическую гарантию страницы, Page — за явную композицию shell.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Публичный API

{% endcard_header %} {% card_body %}
page
Корневой block-tag страницы. Содержит AppBar, другие верхние области и один или несколько явных блоков содержимого.
page_content
Основная область страницы. Получает доступное пространство и содержит пользовательский Layout.
id
Добавляет идентификатор, если shell нужно найти из прикладного JavaScript или использовать как HTMX-target.
class_name и attrs
Добавляют прикладной класс и обычные HTML-атрибуты, не меняя контракт Page.
{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Что размещать внутри

{% endcard_header %} {% card_body %}

Непосредственно внутри Page:

  • AppBar;
  • другие крупные shell-области;
  • page_content.

Внутри page_content:

  • Container;
  • Grid;
  • Stack;
  • Panel, Card и прикладные компоненты.

Page не навязывает внутреннюю разметку. Разделение рабочей области выполняет Layout.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

HTMX и runtime

{% endcard_header %} {% card_body %}

Page не имеет собственного JavaScript API и не требует mount/unmount.

Обычно Page остаётся стабильной оболочкой, а HTMX заменяет содержимое внутри page_content, Panel или другой вложенной области.

Полная замена Page допустима при обычной навигации, но для частичных обновлений выгоднее сохранять shell и менять только внутренние компоненты.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Theme tokens

{% endcard_header %} {% card_body %}

Page использует минимальный набор токенов поверхности страницы. Конкретный список следует брать из manifest текущей реализации.

  • --rui-page-background
  • --rui-page-foreground
  • --rui-page-content-background
  • --rui-page-content-padding

Приоритет: базовые tokens → активная light/dark theme → пользовательская тема → локальные custom properties.

Страница с AppBar и рабочей областью

{% verbatim %}{% page %}
  {% appbar behavior="sticky" surface="glass" %}
    ...
  {% endappbar %}

  {% page_content %}
    {% grid columns=5 %}
      {% container column=1 %}
        {% panel surface="sidebar" height="full" %}
          ...
        {% endpanel %}
      {% endcontainer %}

      {% container column=4 %}
        {% panel width="full" height="full" %}
          ...
        {% endpanel %}
      {% endcontainer %}
    {% endgrid %}
  {% endpage_content %}
{% endpage %}{% endverbatim %}
