Особенности работы

  • Ctrl/Cmd + K открывает палету из любого места страницы.
  • Ввод в поле выполняет фильтрацию по label и keywords.
  • Стрелки меняют active, Enter запускает команду, Escape закрывает палету.
  • После выбора фокус возвращается на элемент, который открыл палету.
  • Выбор одной из трёх demo-команд показывает Toast с переданным действием.

Палета отправляет событие rui:commandselect с detail.action и выбранным detail.item.
