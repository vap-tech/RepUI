AppBar

AppBar — полноширинная верхняя область страницы для размещения навигации, меню, поиска, кнопок, карточек состояния и других компонентов.

{% endcard_header %} {% card_body %}

Статус | Stable

Использовать | Для верхней области Page, которая либо уезжает вместе со страницей, либо остаётся сверху при прокрутке.

Не использовать | Для внутренней раскладки содержимого. Размещение элементов внутри AppBar выполняют Container, Grid, Stack и сами вложенные компоненты.

AppBar не показан внутри рабочей области: компонент относится к shell страницы. Элементы ниже управляют AppBar самого Workbench.

Управление AppBar Workbench

Изменения применяются сразу, без перезагрузки страницы.

Публичный API

{% endcard_header %} {% card_body %}
behavior
static — AppBar находится в потоке и уезжает вместе со страницей. sticky — остаётся сверху.
surface
Открытое имя поверхности для темы. Дефолтная тема содержит default, solid, transparent и glass.
id
Нужен, если AppBar должен быть доступен для runtime-управления.
class_name и attrs
Добавляют прикладной класс и обычные HTML-атрибуты.
{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Runtime API

{% endcard_header %} {% card_body %}
  • getAppBarState(appbar)
  • setAppBarBehavior(appbar, behavior)
  • toggleAppBarBehavior(appbar)
  • setAppBarSurface(appbar, surface)
  • mountAppBarControls(root)

После изменения AppBar отправляет событие repui:appbarchange. В event.detail находятся актуальные behavior и surface.

Theme tokens

{% endcard_header %} {% card_body %}
  • --rui-appbar-background
  • --rui-appbar-foreground
  • --rui-appbar-border
  • --rui-appbar-shadow
  • --rui-appbar-backdrop-filter
  • --rui-appbar-padding-block
  • --rui-appbar-padding-inline
  • --rui-appbar-z-index
  • --rui-appbar-sticky-offset
  • --rui-appbar-transition

Приоритет: базовые tokens → активная light/dark theme → surface → пользовательская тема → локальные custom properties.

Примеры

{% endcard_header %} {% card_body %}

Обычная шапка страницы

{% verbatim %}{% appbar behavior="static" surface="solid" %}
  ...
{% endappbar %}{% endverbatim %}

Закреплённая стеклянная область

{% verbatim %}{% appbar
  id="main-appbar"
  behavior="sticky"
  surface="glass"
%}
  {% grid columns=4 %}
    ...
  {% endgrid %}
{% endappbar %}{% endverbatim %}

Изменение во время работы

import {
  setAppBarBehavior,
  setAppBarSurface,
} from "/static/repui/components/appbar/appbar.js";

const appbar = document.querySelector("#main-appbar");

setAppBarBehavior(appbar, "sticky");
setAppBarSurface(appbar, "glass");
