Public API

{% endcard_header %} {% card_body %}
  • {% templatetag openblock %} drawer id="..." {% templatetag closeblock %} создаёт Drawer.
  • side="left|right" выбирает сторону открытия.
  • variant="modal|persistent" выбирает режим панели.
  • aria_label задаёт доступное имя.

Trigger открывает панель через data-rui-drawer-open="demo-drawer". Runtime Drawer ищет trigger по ID.

Close marker

{% endcard_header %} {% card_body %}

data-rui-drawer-close — marker закрытия. Он должен находиться внутри конкретного Drawer и закрывает только содержащую его панель. 

{% templatetag openblock %} button data-rui-drawer-close=True {% templatetag closeblock %}
                    Закрыть
                    {% templatetag openblock %} endbutton {% templatetag closeblock %}

Значение marker не используется. Внешняя кнопка с data-rui-drawer-close="demo-drawer" пока не является поддержанным способом закрытия.
