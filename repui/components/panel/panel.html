Panel

Panel — базовая поверхность RepUI для размещения содержимого внутри уже выделенной области.

{% endcard_header %} {% card_body %}

Статус | Stable

Использовать | Для sidebar, workspace, внутренних областей страницы и других поверхностей без собственного поведения.

Не использовать | Как замену Layout. Panel не делит пространство на строки и колонки и не управляет расположением соседних элементов.

Panel не имеет JavaScript API, listeners, mount/unmount или собственного runtime-состояния.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Пример

Panel может занимать размер по содержимому или всю доступную область.

{% endcard_header %} {% card_body %} {% panel surface="default" width="full" %}

Внутрь можно помещать обычный HTML, Layout и любые компоненты RepUI.

Назначение surface

{% endcard_header %} {% card_body %}

surface — открытое имя поверхности для Theme. Оно не включает поведение и не ограничено закрытым списком.

Например, sidebar может использовать surface="sidebar", а рабочая область — surface="default".

Если тема не содержит правила для указанного значения, Panel продолжает использовать базовые токены.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Публичный API

{% endcard_header %} {% card_body %}
surface
Открытое имя поверхности для CSS-темы. По умолчанию default.
width
content — ширина по содержимому, full — вся доступная ширина.
height
content — высота по содержимому, full — вся доступная высота.
column и row
Позволяют Panel занять выделенную часть родительского Layout.
id, class_name, attrs
Добавляют идентификатор, прикладной класс и обычные HTML-атрибуты.
{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Что можно вкладывать

{% endcard_header %} {% card_body %}
  • обычный семантический HTML;
  • Container, Grid и Stack;
  • Button, Card и другие компоненты;
  • HTMX-фрагменты;
  • другую Panel, если это действительно отдельная поверхность.

Размер и расположение вложенных элементов определяют сами элементы и Layout. Panel не навязывает им собственную сетку.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

HTMX

{% endcard_header %} {% card_body %}

Panel безопасно заменяется через innerHTML и outerHTML.

Повторная инициализация и cleanup не нужны: Panel не создаёт обработчики, observers или timers.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Theme tokens

{% endcard_header %} {% card_body %}
  • --rui-panel-background
  • --rui-panel-foreground
  • --rui-panel-border
  • --rui-panel-radius
  • --rui-panel-shadow
  • --rui-panel-backdrop-filter
  • --rui-panel-padding

Приоритет: базовые tokens → активная light/dark theme → surface → пользовательская тема → локальные custom properties.
