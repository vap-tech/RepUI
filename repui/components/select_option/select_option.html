Публичный API

{% endcard_header %} {% card_body %}
  • value — обязательное значение.
  • selected — начальное selected-состояние.
  • disabled исключает пункт из interaction-навигации.

Для keyboard-группы runtime подключается явно через mountSelectOptions(root).
