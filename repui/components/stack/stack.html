Stack

Stack раскладывает дочерние элементы по вертикали и задаёт единое расстояние между ними через {% inline_code %}spacing{% endinline_code %}.

{% endcard_header %} {% card_body %}

По умолчанию элементы идут естественным потоком и не растягивают друг друга. Stack не добавляет содержимым собственную семантику.

Используйте его для группировки полей, карточек, действий и других элементов, которым нужен одинаковый вертикальный ритм.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Spacing

Расстояние задаётся токенами Layout.

{% endcard_header %} {% card_body %} {% stack spacing="sm" %}
none — без расстояния
xs — минимальный отступ
sm — компактная группа
md — обычный ритм
lg — крупное разделение
{% endstack %} {% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Варианты раскладки

{% endcard_header %} {% card_body %}

Обычный Stack использует высоту содержимого. Параметр {% inline_code %}rows{% endinline_code %} нужен для явного деления конечной области на строки. 

{% verbatim %}{% stack spacing="md" %}
  ...
{% endstack %}

{% stack rows=20 spacing="none" %}
  {% container row=1 %}Header{% endcontainer %}
  {% container row=19 %}Body{% endcontainer %}
{% endstack %}{% endverbatim %}

Доступные значения: {% inline_code %}none{% endinline_code %}, {% inline_code %}xs{% endinline_code %}, {% inline_code %}sm{% endinline_code %}, {% inline_code %}md{% endinline_code %}, {% inline_code %}lg{% endinline_code %}. Для явных строк дополнительно доступны {% inline_code %}row_size="fill|content"{% endinline_code %}, {% inline_code %}row{% endinline_code %} и {% inline_code %}id{% endinline_code %}/ {% inline_code %}class_name{% endinline_code %}.
