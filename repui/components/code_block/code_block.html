Публичный API

{% endcard_header %} {% card_body %}
  • language — подпись языка.
  • copy=True — добавить copy action.
  • height задаёт максимальную высоту scroll area.
  • Content экранируется и не исполняется как HTML.

Runtime подключается явно через mountCodeBlocks(root).
