Toast

Временное уведомление поверх страницы.

{% endcard_header %} {% card_body %} {% button variant="filled" color="primary" data-rui-toast="Сохранено" data-rui-toast-description="Toast показан через глобальный Workbench region." %} Показать Toast {% endbutton %}

Как это работает

  • mountToasts(document) подключает explicit runtime.
  • Кнопка с data-rui-toast передаёт title уведомления.
  • data-rui-toast-description задаёт дополнительное описание.
  • Toast автоматически исчезает через заданный duration.
  • Кнопка × закрывает конкретное уведомление.
  • Несколько Toast складываются в одну очередь региона.
  • Регион использует aria-live="polite".
  • В Workbench region находится в shell, поэтому Toast не зависит от текущей карточки или HTMX-фрагмента.

Runtime API

const [toast] = mountToasts(document);

toast.show({
  title: "Сохранено",
  description: "Изменения применены.",
  duration: 4200,
});

toast.close(element);
toast.destroy();

Theme contract

Положение задают токены --rui-toast-inset-inline-end и --rui-toast-inset-block-end. По умолчанию Toast находится справа снизу viewport.
