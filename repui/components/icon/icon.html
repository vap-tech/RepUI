Icon рядом с текстом

Для устойчивого выравнивания используйте явную композицию.

{% endcard_header %} {% card_body %}

Голый inline SVG участвует в baseline-выравнивании текста. Для коротких и длинных строк, особенно с кириллицей, это может выглядеть неровно.

{% icon "info" %} Так выглядит рекомендуемая композиция. 

<span class="rui-icon-label">
  {% templatetag openblock %} icon "info" {% templatetag closeblock %}
  <span>Информация</span>
</span>
  • {% inline_code %}Icon{% endinline_code %} остаётся нейтральным и не меняет глобальный baseline.
  • {% inline_code %}.rui-icon-label{% endinline_code %} задаёт {% inline_code %}inline-flex{% endinline_code %}, {% inline_code %}align-items: center{% endinline_code %} и gap.
  • Контейнер подходит для Button, Chip, MenuItem, Alert и обычного текста.
  • Для длинного текста сохраняется естественное поведение wrapping.
