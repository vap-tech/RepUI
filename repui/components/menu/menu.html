Контракт

{% endcard_header %} {% card_body %}
  • Контейнер — role="menu".
  • Пункты — menuitem.
  • orientation и loop задаются у Menu.
  • Disabled items исключаются из навигации.
  • Runtime подключается явно через mountMenus(root).
  • Публичный API runtime: refresh(), focusFirst(), focusLast(), focusCurrent(), items, destroy().

Композиция

Menu не знает, кто его открыл.

{% endcard_header %} {% card_body %}

DropdownMenu добавляет trigger, OverlayPortal и закрытие после выбора.

Menubar размещает несколько trigger по горизонтали и использует Menu внутри каждого раздела.

ContextMenu может открыть тот же Menu по правому клику.

Popover может содержать Menu, если внешний компонент отвечает за размещение и lifecycle.

Таким образом, Menu отвечает за пункты, focus и activation, а внешний компонент — за trigger, overlay и позиционирование.

{% endcard_body %} {% endcard %} {% card width="full" %} {% card_header %}

Где использовать

{% endcard_header %} {% card_body %}
  • статичная панель действий без popup;
  • содержимое DropdownMenu;
  • выпадающие разделы Menubar;
  • контекстное меню и меню внутри Popover.

Если нужен trigger или popup, используйте композицию, а не добавляйте эту ответственность в Menu.
