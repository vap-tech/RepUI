Проверка фильтрации

{% endcard_header %} {% card_body %}
  1. Пустое поле открывает список вариантов.
  2. Значение без совпадений не открывает popup и не показывает «Ничего не найдено».
  3. После повторного фокуса popup открывается, если совпадения появились.
  4. Открытый popup закрывается при уходе фокуса в другое место.
