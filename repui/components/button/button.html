Button

Кнопка запускает действие пользователя. Используйте её для отправки формы, подтверждения операции, запуска загрузки или другого явного действия.

Stable
Использовать
Для действий, submit и подтверждений.
Не использовать
Для обычной навигации или постоянного переключателя состояния.
