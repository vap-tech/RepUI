Демонстрационный Dialog

Фокус перемещается внутрь окна, а после закрытия возвращается на trigger.

{% button variant="text" data-rui-dialog-close=True %} Закрыть {% endbutton %} {% enddialog %}

Как это работает

  • mountDialogs(document) подключает explicit runtime.
  • data-rui-dialog-open="demo-dialog" открывает конкретный Dialog.
  • data-rui-dialog-close закрывает Dialog изнутри.
  • Escape закрывает верхний Dialog в modal stack.
  • Tab и Shift+Tab остаются внутри окна.
  • После закрытия focus возвращается на trigger.
  • При открытом modal Dialog body получает scroll lock.

Runtime API

const [dialog] = mountDialogs(document);
dialog.open(trigger);
dialog.close();
dialog.destroy();
