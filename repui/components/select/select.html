Select

Select выбирает одно или несколько значений. Источником истины остаётся настоящий HTML <select>, поэтому Django forms, browser validation и отправка формы работают без адаптеров.

{% endcard_header %} {% card_body %}

Статус: Stable

Использовать: для выбора из заранее известного списка.

Не использовать: для свободного поиска и ввода — для этого нужен Combobox.

Публичный API

{% endcard_header %} {% card_body %}
name
Имя поля Django form.
multiple
Разрешает несколько выбранных значений.
placeholder
Текст при отсутствии выбранных option.
empty_text
Текст при отсутствии option.
disabled
Полностью отключает поле.
readonly
Запрещает изменение без удаления значения из формы.
required
Использует native validation.
size
sm, md, lg.

Django template note: открывающий block-tag {% verbatim %}{% select ... %}{% endverbatim %} с параметрами пишите одной строкой. Многострочный opening tag может нарушить распознавание {% verbatim %}{% endselect %}{% endverbatim %}.

select.focus();
select.refresh();
select.value = ["python", "django"];
select.destroy();
