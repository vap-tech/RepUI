Оглавление
Collection vertical slice

Listbox, Select, Combobox

Живой preview и его исходный код находятся в одном compositional component. Поведение подключается напрямую из generated bundle rui-core.

Core binding

Listbox

Стрелки, Home/End, pointer selection и active state принадлежат CollectionController.

<div data-rui-listbox role="listbox">
  <button data-rui-option data-value="voronezh">Воронеж</button>
  <button data-rui-option data-value="liski">Лиски</button>
</div>
Select

Select

Keyboard navigation, typeahead, disabled options и hidden input для Django.

<div class="rui-select" data-rui-select>
  <input type="hidden" name="settlement">
  <button data-rui-select-trigger>Выберите пункт</button>
  <div data-rui-select-content>…</div>
</div>
Editable collection

Combobox

Input, popup, filtering и hidden value связаны через ComboboxController.

<div data-rui-combobox class="rui-combobox">
  <input data-rui-value name="organization" type="hidden">
  <div class="rui-control">
    <input class="rui-input rui-combobox__input" data-rui-input>
  </div>
  <div class="rui-combobox__content" data-rui-popup>…</div>
</div>
