# Roadmap

## 0.8.2.5 — Documentation components

- [x] Example preview/source composition.
- [x] Code Block with copy action.
- [x] Dependency-free HTML highlighting.
- [x] Migrate composition demos away from detached dark snippets.

## 0.8.1 — Composition primitives

- Hero anatomy and responsive split layout
- Card header, title, description, body, and footer anatomy
- Playground migration to public composition primitives

## 0.8.0.4 — Component typography isolation

- Fieldset
- Choice
- ChoiceGroup
- FieldError
- Native DateTime field

A fully custom calendar/date-time picker remains intentionally deferred until native-control limitations are demonstrated by real integrations.

## 0.7.0 — Stable foundation

- Current component behavior, accessibility, keyboard navigation, and playground examples are accepted as the stable baseline.
- Existing architectural decisions and dependency direction remain the contract for future work.

## 0.8–0.9 — Focused expansion

- Expand one coherent product area at a time rather than adding unrelated components.
- Continue Django integration, templates, forms, packaging, and documentation without weakening primitive boundaries.
- Preserve the established accessibility and interaction-ownership contracts.

## 1.0 — Compatibility contract

- Publish a formal public API and compatibility policy.
- Define deprecation and migration rules.
