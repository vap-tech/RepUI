Когда компонент считается готовым

Готовность — это проверяемый контракт, а не только наличие шаблона.

{% endcard_header %} {% card_body %}
  • минимальный HTML и нативная семантика;
  • мышь, touch и клавиатура;
  • light/dark во всех официальных темах;
  • disabled, focus, error и loading;
  • повторный mount после HTMX swap;
  • валидация Django tag API;
  • тесты и Workbench-страница;
  • нет hardcoded цветов и layout overrides темы.
{% alert tone="neutral" %}RepUI не стремится копировать каталоги MUI, Ant Design, Bootstrap или Chakra UI. Это серверная Django-библиотека: React и обязательный клиентский runtime не входят в её архитектуру. Новый компонент появляется, когда у него есть реальный серверный сценарий и устойчивый контракт.{% endalert %} {% endcard_body %} {% endcard %} {% endstack %} {% endcontainer %} {% endpage_content %} {% endpage %} {% include "workbench/partials/appbar_runtime.html" %}
