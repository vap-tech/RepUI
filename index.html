COMPOSITION

Card anatomy

Card задаёт структуру, а не тип содержимого. Header, body и footer работают независимо.

Полная анатомия

Заголовок и описание принадлежат компоненту и не зависят от внешней типографики.

Body принимает произвольный семантический HTML и сохраняет предсказуемый внутренний ритм.

Совместимо

Только body

Существующий паттерн остаётся рабочим, а области можно добавлять по мере необходимости.

HTML
<article class="rui-card">
  <header class="rui-card__header">
    <h3 class="rui-card__title">Title</h3>
    <p class="rui-card__description">Description</p>
  </header>
  <div class="rui-card__body">...</div>
  <footer class="rui-card__footer">...</footer>
</article>

01 · Contract

Стандарт RepUI

В 0.4 зафиксированы единые соглашения для дальнейших компонентов.

HTMLПрефикс rui-, поведение через data-rui-*, состояние через ARIA и data-атрибуты.
JavaScriptАвтоинициализация плюс классы RepUI.Select, RepUI.Combobox и события rui:*.
AccessibilityListbox semantics, active descendant, keyboard navigation, visible focus и восстановление фокуса.
DjangoОбычный hidden input остаётся источником значения для request.POST.
Контракт размещения в playground

Information — всё, что не является UI-компонентом. Primitives — элементы без зависимостей от других RepUI-компонентов. Components — элементы, которые используют хотя бы один RepUI-примитив или компонент.

Высокоуровневый компонент может потреблять низкоуровневый примитив, но не расширяет его API.

QUALITY

Как тестировать

Идите сверху вниз по одной странице. У каждого компонента рядом указан короткий сценарий. Отдельные QA-страницы удалены: они вернутся только для настоящих стресс-тестов, когда это станет необходимо.

Порядок проверки1. Мышь: hover, click, outside click.2. Клавиатура: Tab, Shift+Tab, стрелки, Enter, Space, Escape.3. Состояния: disabled, empty, open/closed, selected.4. Окружение: светлая/тёмная тема, scroll, resize и масштаб 125–150%.
17 · Release QA

Interactive Stress Pass

Каждый сценарий вынесен в отдельный тестовый блок: сначала цель, затем живой компонент и точные ожидаемые результаты.

Сценарий A · Длинный Listbox

Фокус остаётся внутри списка. Стрелки цикличны, активная строка автоматически прокручивается в видимую область, повтор «П» перебирает совпадения.

Что проверить
  • Удерживайте ↓: активная строка всегда видна
  • После последней строки ↓ возвращает к первой
  • Повторяйте «П»: Павловск → Панино → Поворино → Подгоренский
Сценарий B · Select у нижней границы

Большая пустая область здесь намеренная: она ставит trigger у нижнего края viewport и проверяет flip панели вверх.

Что проверить
  • Откройте Select: панель появляется над trigger
  • На панели выставляется data-side="top"
  • Высота ограничивается, а активный пункт остаётся видимым
Primitive · Text

Assistive Text

Независимый однострочный примитив для краткой подсказки или результата проверки. Он не знает о Password Input и не выполняет валидацию.

Что проверить
  • Пустое поле показывает состояние base
  • 1–11 символов переключают строку в negative
  • 12-й символ переключает строку в positive без сдвига формы
Base

Введите минимум 12 символов.

Negative

Минимум 12 символов.

Positive

Пароль подходит.

HTML
<p class="rui-assistive-text" data-state="base">Подсказка.</p>
<p class="rui-assistive-text" data-state="negative">Ошибка.</p>
<p class="rui-assistive-text" data-state="positive">Готово.</p>
CSS
.rui-assistive-text

data-state="base | negative | positive"

Component · Form

Password Input

Составной компонент: Input + action-кнопка + AssistiveText. Password Input знает о примитивах, но не добавляет password-состояния в их API.

ЗависимостиInputButtonAssistiveText
Что проверить
  • Кнопка меняет имя Показать/Скрыть пароль
  • Текст меняет base → negative → positive без сдвига
  • Ошибка отражается через aria-invalid на input

Введите минимум 12 символов.

HTML
<input aria-describedby="password-assist" type="password">
<button type="button" aria-label="Показать пароль">Показать</button>
<p class="rui-assistive-text" data-state="base" id="password-assist">
  Введите минимум 12 символов.
</p>
Text
Композиция, а не новый низкоуровневый API.

Password Input владеет:
- переключением type=password/text;
- aria-label кнопки;
- правилами проверки;
- aria-invalid и обновлением текста.

Input, Button и AssistiveText остаются универсальными.

Command Palette

Stress fixture содержит 50 команд. Палитра остаётся компактной: список прокручивается, группы фиксируются, фильтр сообщает число совпадений. Открывается через Ctrl + K или ⌘ + K.

ЗависимостиInputListbox
Что проверить
  • ⌘K / Ctrl+K открывает и выделяет запрос
  • Home/End — каретка; Ctrl+Home/End — список
  • Tab остаётся внутри; Escape возвращает фокус
  • 50 команд не растягивают dialog; активная строка всегда видна
  • Поиск скрывает пустые группы и обновляет счётчик
50 команд распределены по пяти группам. Команды генерируют rui:commandselect; навигацию можно связать с URL, drawer, dialog или пользовательским обработчиком.
