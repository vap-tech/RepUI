# 008 — Layered primitives

**Status:** Accepted in 0.6.5.

RepUI стандартизирует поведение и визуальный контракт примитивов, а не содержимое прикладного интерфейса.

Высокоуровневый компонент может использовать низкоуровневый, но не расширяет его API и не добавляет в него знания о своём сценарии.

Пример зависимости:

```text
Tokens → Assistive Text → Password
```

`Password` может выбирать текст и состояние Assistive Text. Assistive Text не знает о паролях, требованиях, strength meter или списках правил.

Для Assistive Text зафиксирован минимальный контракт:

- одна строка;
- состояния `base`, `negative`, `positive`;
- содержимое заменяется потребителем;
- связь с контролом выполняется стандартным `aria-describedby`;
- прикладная валидация остаётся вне примитива.
