# 008 — Layered primitives

**Статус:** принято

## Решение

RepUI стандартизирует behavior и visual contract primitives, а не содержимое прикладного интерфейса.

Высокоуровневый component может использовать низкоуровневый, но не расширяет его API и не добавляет в него знания о собственном use case.

Пример зависимости:

```text
Tokens → Field → Select / Combobox
```

Общий слой владеет только общими состояниями и semantics. Прикладная validation, тексты и бизнес-правила остаются у потребителя.
