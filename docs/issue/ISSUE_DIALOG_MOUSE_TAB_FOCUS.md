# Dialog: focus-visible после открытия мышью

## Сценарий

1. Открыть Dialog кликом мыши по trigger.
2. Нажать `Tab`.
3. Проверить первый focusable control внутри Dialog.

## Ожидаемое поведение

После перехода по `Tab` на control появляется обычная keyboard focus-visible
рамка, даже если Dialog был открыт мышью.

## Текущее поведение

Dialog получает focus, но после открытия мышью визуальная focus-visible рамка
на control не появляется или ведёт себя непредсказуемо.

## Ограничения

Не менять текущую механику открытия и focus trap без отдельной проверки
keyboard-сценария. При открытии через `Enter` рамка отображается корректно.

## Что проверить при исправлении

- открытие мышью + `Tab`;
- открытие через `Enter`;
- `Shift+Tab`;
- повторный переход `Tab` при одном focusable control;
- restore focus после закрытия;
- light и dark theme;
- отсутствие ложного focus ring при чистом открытии мышью.
